  • This host: Linux x86_64 (Pop!_OS), Ghostty terminal, no tmux installed. Installed provider CLIs are Claude Code 2.1.283 and Codex 0.157.0, the candidate baselines; Lavish is 0.1.79.
  • Things that cannot be produced on demand: a provider's allowance running out (it would spend your own usage for hours or days), and a native modal the provider chooses to show, such as the Codex rate-limit model-switch prompt the feasibility probe met. A modal can be opened on purpose, and sign-out, crashes, reboots, lost hooks and network loss can all be caused deliberately.
  • Provider sign-in cannot go into hosted CI: AsmAI never collects or transfers provider tokens (Choose runtime adapters and authentication), so anything needing a real signed-in provider runs on a real host.
  • Draft PRs: the "[not ready]" fallback needs GitHub to refuse a draft, which depends on the account's plan and the repository's visibility. If no repository available to the harness refuses drafts, the refusal has to be simulated at the gh boundary.
