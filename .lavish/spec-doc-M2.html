M2 Both providers and skills

M2 widens the walking skeleton to both providers and gives agents their skills: Codex sessions and mixed staffing, the setup commands and the full configuration file, the skill bundle with its per-session delivery and hiding, and platform certification checks. M1's cases run again on Codex (AssemblyAI#27).

What it adds

  1. Codex sessions and mixed staffing. Any role's leader and workers can run on either provider, and one job can mix them (AssemblyAI#27, 03, 07).
  2. Setup: asmai providers install for every pinned provider, asmai init and asmai doctor, completing the minimal forms M1 built (AssemblyAI#27, 09, M1).
  3. The configuration file with every field, asmai config check|show|edit|apply and asmai role list|set (AssemblyAI#27, 09).
  4. The skill bundle, the operating guide, the skill lists and leaders' indexes, per-session delivery to each provider, and hiding everything else (AssemblyAI#27, 08).
  5. Platform certification checks at init, doctor and start, and refusal of provider versions that are not pinned (AssemblyAI#27, 03).
  6. M1's cases rerun on Codex in the harness (AssemblyAI#27).

Builds on

M1 Walking skeleton: the daemon, the store, Claude sessions and the end-to-end path to a tested pull request.
