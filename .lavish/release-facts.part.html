What I checked

Checked on 2026-10-05 and 2026-10-06 from GitHub and official documentation. These are facts for your decisions, not decisions.

  • This repository. talvor/AssemblyAI is public and has no license. Neither talvor/asmai nor talvor/homebrew-tap exists yet.
  • Licenses around AsmAI. Bundled skills (mattpocock/skills): MIT. Lavish, Firstmate and no-mistakes: MIT. OpenRig and Codex: Apache-2.0. Claude Code: no open-source license; its use is governed by Anthropic's terms. AsmAI redistributes none of the providers, because asmai providers install fetches them from official channels.
  • Homebrew. Homebrew 5.0.0 (12 November 2025) deprecated --no-quarantine, deprecated casks without code signing, and disables casks in Homebrew's own cask repository that fail Gatekeeper in September 2026. Casks work better on Linux than before. Intel macOS moves to Tier 3 in September 2026 and is unsupported from September 2027.
  • GoReleaser. Since v2.10 its Homebrew formula output is deprecated in favour of casks. For unsigned executables it offers a hook that runs xattr -dr com.apple.quarantine, warning that this circumvents Gatekeeper and that Apple may stop it working. It can sign and notarize, which needs Apple's yearly fee.
  • macOS signing. Apple silicon runs only signed code. Go's linker gives each darwin/arm64 executable an ad-hoc signature. Gatekeeper checks for a Developer ID and notarization only on quarantined files. Browsers set quarantine and curl does not. Homebrew quarantines cask downloads but not formula downloads.
  • Provenance. GitHub artifact attestations are free for public repositories (private ones need Enterprise Cloud). They are recorded in Sigstore's public-good transparency log and checked with gh attestation verify (gh 2.49 or newer). No signing key is kept.
  • SQLite without a C compiler. modernc.org/sqlite is a CGo-free SQLite for Linux and macOS on x86_64 and arm64, so one Linux machine can build every platform. The C library via cgo is faster but needs a C toolchain per target.
  • Name reservations. npm: “It is against npm's Terms of Use to publish a package … simply for the purposes of reserving it for future use.” crates.io forbids crates that exist “only to reserve a name … without having any genuine functionality,” and may delete them. homebrew-core accepts only notable projects, built from source; a tap is your own repository.
