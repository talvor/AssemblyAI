# Choose inspiration versus reuse of reference systems

Type: grilling
Label: wayfinder:grilling
Parent: ../map.md
Blocked by: 01

## Question

Should the factory be a new implementation informed by Firstmate/OpenRig, an extension of one reference, or a wrapper around selected components? The intended OpenRig project is confirmed as mvschwarz/openrig. Assess compatibility, maintenance burden, packaging boundaries, and licenses before choosing reuse. The research identified useful mechanisms but did not establish a stable embeddable library interface.
